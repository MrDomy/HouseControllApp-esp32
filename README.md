# Makarov House (Learn Up) 🏠✨

Умный дом на базе ESP32 с управлением через Android-приложение (Jetpack Compose).
Проект разработан в рамках финальной защиты.

## Особенности и Функционал
* **Управление дверью**: Открытие и закрытие поршневой двери (драйвер L298N).
* **Управление светом (Реле)**: Включение и выключение основного освещения (Flashlights).
* **Адресная светодиодная лента (WS2812B)**: 
  * 17 светодиодов с индивидуальным управлением.
  * Цветовой круг (Color Wheel) для удобного выбора цвета (HEX/HSV).
  * Управление группами светодиодов.
* **Режим "Дискотека"**: Динамичное переливание цветов с неблокирующим таймером (`millis()`).
* **Режим "Охрана" (Security Mode)**:
  * Интеграция с инфракрасным датчиком (IR Sensor).
  * Автоматический переход в режим тревоги при обнаружении движения, если дом поставлен на охрану.
* **Аварийный режим (Emergency)**: 
  * Мигающий красный свет по всему дому.
  * Автоматическое открытие двери для безопасной эвакуации.

## Архитектура
Проект построен по принципам Clean Architecture и разделен на две основные части:

1. **Android App (Kotlin & Jetpack Compose)**
   * **UI/UX**: Современный интерфейс в едином брендинге (Learn Up), плавная анимация.
   * **Слои**: Разделение на экраны (`MakarovHouseApp.kt`), компоненты (`LedComponents.kt`, `ColorWheel.kt`) и темы (`Theme.kt`, `Color.kt`).
   * **Логика**: Вынесена в `ControlManager.kt` (MVVM), состояние хранится в `StateFlow`.
   * **Сетевой слой**: Отправка HTTP GET запросов на микроконтроллер с автоматическим поллингом статуса каждые 2 секунды.

2. **ESP32 Firmware (C++)**
   * Развернут локальный WebServer на порту `80`.
   * Неблокирующая архитектура (отказ от `delay()` в пользу таймеров `millis()`).
   * Локальная Wi-Fi точка доступа (`MakarovHouse` / `12345678`).

## Установка и Запуск

### ESP32 (Прошивка)
1. Откройте файл `esp32_firmware/esp32_firmware.ino` в Arduino IDE.
2. Убедитесь, что установлена библиотека **Adafruit NeoPixel**.
3. Подключите ESP32, выберите нужный COM-порт и нажмите "Загрузить".
4. Подключитесь с телефона к Wi-Fi сети `MakarovHouse` (пароль `12345678`).

### Android App
1. Откройте папку `app` в Android Studio.
2. Подключите Android-устройство (или эмулятор) и нажмите "Run" (`Shift + F10`).
3. В приложении убедитесь, что IP-адрес указан как `192.168.4.1`.

## CI/CD (GitHub Actions)
В проекте настроен автоматический пайплайн (Continuous Integration).
При каждом пуше в ветку `main` GitHub Actions автоматически собирает:
1. Android APK файл (`app-debug.apk`), который можно сразу скачать из артефактов.
2. Прошивку ESP32 для проверки отсутствия ошибок компиляции.
