## 🚀 Особенности и Функционал

### Аппаратная часть
* **Управление дверью (L298N)**: Интеллектуальное управление поршневым механизмом с встроенным **аппаратным предохранителем** (автоотключение тока через 2.5 секунды для защиты мотора от сгорания).
* **Свет (Реле)**: Синхронное управление основным освещением.
* **Адресная лента WS2812B (17 LED)**: Индивидуальное управление каждым диодом, группировка, защита от просадок напряжения (Brownout protection).
* **Инфракрасный датчик (IR Sensor)**: Аппаратная защита от дребезга (debounce) и мгновенное срабатывание режима тревоги.

### Смарт-сценарии
* 🪩 **Режим "Дискотека"**: Динамичное переливание ярких насыщенных цветов с использованием неблокирующих таймеров.
* 🛡️ **Режим "Охрана"**: Активация датчиков движения. Ручное управление цветом блокируется до снятия с охраны.
* 🚨 **Аварийный режим (Emergency)**: При срабатывании ИК-датчика в режиме охраны дом автоматически закрывает дверь для блокировки нарушителя и включает красное мигание.

## 🏗 Архитектура и Надежность

Проект построен по принципам **Clean Architecture** и способен выдерживать экстремальные нагрузки:

### 1. Android App (Kotlin & Jetpack Compose)
* **MVI (Model-View-Intent)**: Единый источник правды (`StateFlow`). Приложение никогда не рассинхронизируется и не крашится при обрывах сети.
* **Адаптивный UI**: Идеальная работа Темной и Светлой темы (`MaterialTheme`). Все элементы имеют выверенный контраст и элегантный дизайн.
* **Throttling (Защита от DDoS)**: Цветовой круг (HSV Color Wheel) ограничивает отправку HTTP-запросов (не чаще 10 раз в секунду). Это позволяет плавно водить пальцем по палитре, не "вешая" микроконтроллер.
* **Гибридный поллинг**: Фоновая синхронизация с ESP32 каждые 2 секунды + оптимистичное обновление UI при отправке команд.

### 2. ESP32 Firmware (C++)
* **Zero-Blocking Architecture**: Полный отказ от `delay()` в пользу математики `millis()`. ESP32 мгновенно отвечает на HTTP-запросы даже во время тяжелых диско-анимаций.
* **Memory Safety**: Полностью устранены уязвимости классического C++ (включая Stack Buffer Overflow при генерации JSON).
* **Автономность**: ESP32 сама поднимает стабильную Wi-Fi точку доступа (SoftAP).

## 🛠 Установка и Запуск

### ESP32 (Прошивка микроконтроллера)
1. Откройте файл `esp32_firmware/esp32_firmware.ino` в Arduino IDE.
2. Установите библиотеку **Adafruit NeoPixel** через менеджер библиотек.
3. Выберите плату ESP32 Dev Module, укажите COM-порт и нажмите "Загрузить".
4. Подключитесь с телефона к созданной Wi-Fi сети:
   * **SSID:** `MakarovHouse_ESP`
   * **Пароль:** `password123`

### Android App
1. Откройте папку `app` в Android Studio.
2. Соберите проект (`Shift + F10`) и установите на смартфон.
3. В приложении перейдите на вкладку **Settings** и убедитесь, что IP-адрес указан как `192.168.4.1` (IP адрес ESP32 по умолчанию). Вы можете использовать кнопку *Force Sync* для моментального подключения.
